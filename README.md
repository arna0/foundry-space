# 🔭 Foundry Space

**A design study: an online store for astronomy prints.**

Deep-space photographs, Webb infrared images, lunar maps and orbital diagrams sold as made-to-order archival prints. I built it to practise product-page design, animation and visual storytelling on a topic I like.

## Highlights

- ✨ **Animated starfield** drawn on a `<canvas>` behind the hero
- 🪐 **Interactive orrery**: planets orbiting the sun, built as a React component
- 🖼️ **Product detail view** with print, paper and framing options
- 📐 **Framing diagrams** explaining paper types (cotton rag vs. obsidian velvet) and glass options
- 📚 Editorial section with guides about the images and their care

## Run it

```bash
npm install
npm run dev      # http://localhost:3000
```
